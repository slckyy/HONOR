FROZEN RULES
- One canonical PRIVATE GitHub repository only.
- Do not add top-level apps/services/packages that duplicate existing responsibilities without approved CHANGE REQUEST.
- Database migrations live under infrastructure/migrations and are append-only after release.
- Shared contracts are generated from packages/contracts; do not hand-fork API/event/tool types per service.
- Commercial/font/media binaries are not committed unless license explicitly allows repository redistribution.
- Large source/generated media is never committed to Git.
